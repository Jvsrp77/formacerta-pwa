📐 Formulação Matemática da Biomecânica Articular & VBT

O sistema utiliza as coordenadas espaciais tridimensionais $(x, y, z)$ fornecidas pelo modelo BlazePose / MediaPipe Pose para calcular o ângulo formado por três marcadores anatômicos consecutivos $A, B, C$, onde $B$ é a articulação pivô.

Vetor BA: u = (A.x - B.x, A.y - B.y, A.z - B.z)
Vetor BC: v = (C.x - B.x, C.y - B.y, C.z - B.z)

Produto Escalar: u · v = (u.x * v.x) + (u.y * v.y) + (u.z * v.z)
Magnitudes: ||u|| = √(u.x² + u.y² + u.z²), ||v|| = √(v.x² + v.y² + v.z²)

Ângulo Articular (θ): θ = arccos( (u · v) / (||u|| * ||v||) ) * (180 / π)

Velocidade Angular VBT (ω): ω = |θ(t) - θ(t - Δt)| / Δt (deg/s)

Implementação: js/core/geometry.js (cálculo puro) e js/pipeline/etapa3-biomecanica.js (aplicação por frame).
